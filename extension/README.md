# Extension — GLTD Kid Control (escopo futuro)

Extensão para Chrome/Brave que:
- edita a página inicial do YouTube (remove Shorts, recomendações e conteúdo
  que bata nos parâmetros de bloqueio do perfil);
- coleta títulos, thumbs e descrições dos vídeos/canais para reportar ao server;
- integra-se ao client via proxy local no Brave.

Será desenvolvida em prompt posterior, junto com o client/.
